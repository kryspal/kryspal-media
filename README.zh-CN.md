# Kryspal Media

Kryspal Media 是一款快速的自托管媒体服务器：用 Docker 装在 NAS 或小型主机上，指向你的电影和剧集，就能在你已有的设备上观看。

更多介绍、安装与文档请见[官网中文版](https://kryspal.net/zh/)。
